# ♚ ChessMaster

A modern Java Chess game built using Java and Maven.

## ✨ Features

- ♟ Complete chess board with legal piece movement
- ✔ Move validation
- 👑 Check detection
- ☠ Checkmate detection
- 🎨 Beautiful modern UI
- 🔄 Turn-based gameplay
- 🧩 Object-Oriented Design
- 📦 Maven Project

---

## 🚀 Technologies Used

- Java
- Maven
- Eclipse IDE
- Git & GitHub
